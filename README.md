# Climbing Skills Audit

An interactive skill map for climbing technique, rescue and knots. Start at the center and work outward through seven tiers across eleven branches, rating each skill as Learned, Practiced or Drilled.

Open it here: https://bearelykoalified.github.io/climbing-skills-audit/

Progress is saved in your own browser only.

Knot images come from Wikimedia Commons under free licenses (CC BY-SA, CC0 and public domain). Each skill's panel credits the author and license and links to the original file.

This is a checklist, not instruction. Learn rescue, rappel and anchor systems in person from a qualified instructor.
